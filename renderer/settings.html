WorkHUD

A floating window for unread mail, new Slack messages and memory pressure. Drag it where you like, collapse it to a single bar, or expand it to watch both feeds side by side. Everything is stored locally.

Polling

2-5 minutes is the sweet spot while collapsed. Below 2 you burn API quota for little benefit.

The expanded window is one you are actually watching, so it refreshes faster. This is polling, not a live push: nothing appears sooner than the next check. Slack rate-limits at roughly 50 calls a minute and each check costs about one per conversation, so below 30 seconds you risk being throttled.

Google Not connected

Gmail read-only access through your own Google account. WorkHUD never sees your password; Google issues a token that is stored encrypted on this machine.

First time: create a Google OAuth client (about 3 minutes)
  1. Open console.cloud.google.com and create a project (any name).
  2. APIs & Services → Library: search for Gmail API and enable it.
  3. OAuth consent screen: choose Internal if your work account allows it, otherwise External and add your own address under Test users.
  4. Credentials → Create credentials → OAuth client ID. Application type must be Desktop app.
  5. Copy the client ID and client secret into the two boxes below.

A "Desktop app" client is what makes the loopback sign-in work. A "Web application" client will be rejected by Google.

Standard Gmail search syntax, e.g. is:unread in:inbox -category:promotions.

Slack Not connected

Slack does not accept Google as a login for API access. You sign in to Slack in your browser (where your Google SSO applies), Slack issues its own token, and you paste it here once.

First time: create a Slack app and copy the user token
  1. Open api.slack.com/apps → Create New App → From scratch, and pick your work workspace.
  2. Go to OAuth & Permissions and add these under User Token Scopes (not Bot Token Scopes):

    channels:history groups:history im:history mpim:history channels:read groups:read im:read mpim:read users:read search:read

  3. Click Install to Workspace and approve. This is the step where you authenticate with Google.
  4. Copy the User OAuth Token — it starts with xoxp-, not xoxb-.
  5. Paste it below and press Connect.

If your workspace requires admin approval for apps, that request goes to your Slack admin at step 3. search:read is only used for channel mentions and is skipped automatically if your plan does not include search.

Window

The panel shows system memory, then disk space per drive, then the heaviest processes. With every drive ticked, any new one you plug in appears automatically.

WorkHUD also sits in the system tray, next to the clock — possibly behind the overflow arrow. Right-click it for the same controls.
The preview closes as soon as the pointer leaves the bar, so click the chevron or the memory rail to keep it open. Drag the window by its bar or by a column heading. Resize from any edge while expanded; the position and size are remembered.
